# Architecture Decision Records

Each ADR records one significant decision: context, problem, decision,
alternatives considered, and consequences. ADRs are immutable once accepted.
To change a decision, write a new ADR that supersedes the old one.

| ADR | Title | Status |

| [ADR-002](0002-go-for-discovery.md) | Go for resource discovery | Accepted |
| [ADR-003](0003-python-for-policy-and-remediation.md) | Python for policy evaluation and remediation | Accepted |
| [ADR-004](0004-json-schema-contracts.md) | JSON Schema for cross-language contracts | Accepted |

## Template

```
# ADR-NNN: Title
- Status: Proposed | Accepted | Superseded by ADR-XXX
- Date: YYYY-MM-DD

## Context
## Problem
## Decision
## Alternatives considered
## Consequences
```
